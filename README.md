# Krzyżówka React

Prosta krzyżówka o programowaniu wykonana w React.

## Uruchomienie

1. Zainstaluj Node.js.
2. W folderze projektu uruchom `npm install`.
3. Uruchom `npm run dev` i otwórz adres wyświetlony w terminalu.

## Funkcje

- Wpisywanie haseł i wybieranie wskazówek.
- Podświetlanie aktywnego hasła.
- Sprawdzanie poprawności (zielone i czerwone pola).
- Pokazywanie rozwiązania i czyszczenie planszy.
- Testy: `npm test`.
